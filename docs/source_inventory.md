# Release source inventory

The model source, numeric registries, regression tests and interface originate
from the author's CABOMB working project. The empirical methods and response
convolution originate from the subsequent local methods study. Resource loading
and CLI orchestration were adapted in this copy for standalone use. No new
biological parameters were inferred during packaging.

The original model specification is in `model_specification.md` and
`model_specification_v1_3.md`; the follow-up protocol is under
`research/protocol/`. Original numeric evidence labels remain in the registry.
`historical_source_inventory.md` records inspected materials that are not all
distributed here. A historical filename is provenance, not a bundled file.

Literature series used in the prior study are listed in
`research/literature_sources.json`. Source workbooks, paper PDFs, extracted curves
and historical workstation scripts are excluded. The executable example data
are generated mathematically and have no experimental origin.
