# Source Inventory

This inventory is based only on files supplied under `inputs/literature/` and
`inputs/project/`. No network sources were used in this phase.

## Inspection Methods

- PDF files: `pypdf` for metadata and page counts; `pdfplumber` for per-page
  text extraction, table extraction, image/layout object counts, figure/table
  caption clues, and pages with low or missing extracted text.
- DOCX files: `python-docx` for paragraphs, styles, tables, and inline shapes;
  OOXML ZIP inspection for embedded media and comments/footnote/endnote parts.
- PPTX files: `python-pptx` for slide titles, text boxes, tables, and picture
  shapes; OOXML ZIP inspection for notes and media; embedded slide images were
  exported and visually inspected.
- XLSX files: `openpyxl` for worksheets, used ranges, headers, values,
  formulas, cell data types, merged ranges, unit clues, and missing cells.

Temporary extraction outputs were written outside the repository under the
session temp directory. Files under `inputs/` and `data/raw/` were not modified.

  parser-level failure in the final extraction pass.

## Source Use Boundaries

- Project files are treated as project design guidance, not peer-reviewed
  evidence unless they cite a supplied literature file.
- The Excel values are recorded because they are explicit in a supplied file,
  but their row-level literature source is not supplied. They should not be
  described as validated biological constants.
- Docking scores or docking-derived binding energies must not be converted into
  experimental `Kd` values without separate validation.
